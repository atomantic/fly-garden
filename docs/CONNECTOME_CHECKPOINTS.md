# Research connectome state preservation

The sparse research LIF kernel can export and restore schema-version 1 checkpoints. This preserves numerical state, not demonstrated learning, biological memory, or subjective continuity. It does not connect the research backend to the garden registry or implement durable storage. The synthetic fixture remains a separate backend.

`createSparseLif(graph, { individualId, dataset, checkpoint })` accepts either supported exact profile (`male-cns:v1.0`, `banc:v888`). Namespaced graphs can infer their profile for existing diagnostic callers; raw numeric string graphs remain diagnostic-only with a null dataset. Explicit profile construction requires matching namespaced IDs. `individualId` is independent of neuron IDs and dataset identity, generated once per instance if omitted. Reopening a saved individual requires explicitly supplying the same individual ID; checkpoints never silently choose a recipient.

`checkpoint()` returns JSON-compatible copied potential, firing, and refractory arrays, integer tick and cumulative counters, full engineered model parameters, individual/dataset IDs, and a SHA-256 graph identity. The firing array is the pending one-step transmission buffer, including an explicitly requested initial numerical probe. No random state or learning weights exist in this kernel. Graph identity hashes ordered string IDs, length-prefixed little-endian CSR words, and source signs. Hashing is cached once at construction. Callers transfer ownership of graph arrays and must not mutate them afterward. Model parameters and graph identity are validated before any restore; graph data itself is not duplicated in the checkpoint.

`restore(checkpoint)` rejects unexpected fields, incompatible identities/model/graph, invalid dimensions, unsafe clocks/counters, nonfinite voltages, and inconsistent firing/refractory state before replacing authoritative arrays. Each numerical step retains the previous complete state on nonfinite values or unsafe counter overflow. The existing leak, threshold, synaptic delay, refractory timing, and finite-value rule are unchanged; no new arbitrary voltage clipping is introduced.

Validation enforces invariants guaranteed by the update order: maximum refractory duration exists exactly when the pending firing bit is set; tick-zero voltage is reset and refractory state is either unseeded or the explicit initial probe; tick-zero historical counters are zero. After an update, pending spikes cannot exceed cumulative emitted spikes. Cumulative spikes are bounded by `tick × neuronCount` and traversals by `tick × directedEdgeCount`, using exact integer arithmetic for the products. These are necessary state/history constraints, not a claim that arbitrary checkpoint histories can be reconstructed or authenticated. The initial probe intentionally carries pending firing bits without increasing historical spike counters.

`openConnectomeBackend(directory, { dataset, individualId, checkpoint })` loads only locally verified pinned data. Optional initial checkpoint restoration occurs before a paused ready state is exposed. Missing/incompatible files or checkpoint yield unavailable state, with no fixture substitution. Client methods `checkpoint()` and `restore(saved)` complement the existing explicit `start`, `pause`, `probe`, and bounded `advance(1…1000)` calls. There are no timers or automatic probes. Exports are synchronous worker-boundary snapshots; saving them durably and limiting serialization memory remains the caller's responsibility. Full JSON exports allocate arrays and should be budgeted separately from resident CSR memory.

Worker mutations require the current session epoch. A successful restore rotates the epoch and pauses; queued messages carrying the old epoch cannot start or advance the restored state. Invalid restores change neither neural state nor epoch. The client supplies epochs automatically. A checkpoint contains no reusable authorization/session epoch. Checkpoint exports remain possible after numerical faults; validated restoration can recover a faulted worker while paused.

Validation uses three-neuron graphs under both exact namespaces: JSON round-trip at a pending spike boundary then 30 identical continuation steps, incompatible graph/model/recipient/namespace rejection with no partial state change, and paused epoch-rotating worker restoration. Existing independent numerical-reference tests still pass. This is small-fixture evidence; no full neural dataset was run to validate persistence in this change.

Additional boundary tests preserve valid initialization, probes, refractory transitions and silent states, reject impossible state/counter combinations without partial mutation, verify zero-edge traversal bounds, and retain a running worker's epoch/status after a rejected restore. A safe maximum clock checkpoint can be inspected/restored; a subsequent overflow rejects the entire numerical step.
