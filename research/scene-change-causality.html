Garden scene-change GPU raster source

This page is the browser half of one recording. It builds the production Scene.jsx garden scene graph and rasters it through the production 8×4 controller camera on the real graphics device, so that scripts/gpu-scene-change-causality.mjs can close a loop around it. The 32-neuron fixture, the engineered luminance encoding and the declared motor readout run in that driving Node process, never here.

Nothing happens until the button is pressed, and pressing it still starts no simulation, creates no individual, issues no app API call and sends nothing off the loopback interface. It only makes the raster source reachable to whatever drives this page.
